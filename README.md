# 行人的法槌（Walker's Gavel）

填寫[桃園市政府警察局交通違規檢舉系統](https://tvrweb.typd.gov.tw:3444/TTPB/D0101)表單用的 Chrome 擴充功能。把每次都要重打的個人資料加密存在自己的電腦上，並從影片讀出車牌與違規時間，省下重複填寫的時間。

這是個人自用的工具，不是官方軟體，與桃園市政府警察局無關。

## 功能

- **個人資料一鍵填入**：姓名、身分證字號、電子信箱、手機、聯絡地址。
- **從影片填入車牌、日期、時間**：把影片放進網站的「附件 1」，就會讀出影片的拍攝時間填入違規日期與時間，並從檔名填入車牌。
- **從車牌預選車種**：依公路總局的號牌編碼範圍，判斷是汽車、輕型機車、重型機車或大型重型機車；判斷不出來時預選汽車。
- **常用地點、常用違規**：把常填的違規地址與違規事項存起來，之後一鍵套用。各可存 20 筆。
- **檢舉期限提醒**：影片日期超過 7 天，或晚於今天時會提醒，不填入日期與時間。
- **所有存下來的資料都加密**：以主密碼加密後才寫入硬碟，閒置 10 分鐘或關閉瀏覽器後自動鎖定。
- **完全不連網**：擴充功能本身不會傳送任何資料到任何地方。

不會幫你做的事：驗證碼、「我同意以上聲明」的勾選、送出按鈕，永遠由你自己操作。

## 適用範圍

- 只支援桃園市的檢舉系統，其他縣市不適用。
- 只在 macOS 的 Chrome 上開發與測試過。
- 讀取拍攝時間只支援 `.mov` 與 `.mp4`，建議使用手機的原始檔。經過通訊軟體傳送或重新壓縮的影片，拍攝時間可能已經遺失。
- 必須自己先將影片檔名存成車牌號碼才能夠做車種判斷與車牌代填，格式為 `前段-後段`，例如 `ABC-1234.MOV`。
- 影片判讀僅處理「附件 1」。

## 安裝

沒有上架到 Chrome 線上應用程式商店，需要自己載入：

1. 下載或 clone 這個專案。
2. 在 Chrome 開啟 `chrome://extensions`，打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選擇專案資料夾（裡面有 `manifest.json` 的那一層）。

## 使用方式

### 第一次使用

1. 開啟檢舉系統的頁面，右下角會出現「行人的法槌」面板。按「開啟設定頁」。
2. 設定主密碼（至少 8 個字元）。
3. 填好個人資料，按「儲存個人資料」。

**忘記主密碼無法救回**，只能在設定頁「清除所有資料」後重新設定。

### 填寫檢舉人資料（第一頁）

1. 按面板上的「解鎖」，在跳出的小視窗輸入主密碼。
2. 按「填入個人資料」。
3. 自己輸入驗證碼並送出。

已經有內容的欄位不會被覆蓋。

### 填寫檢舉內容（第二頁）

1. 把影片放進網站的「附件 1」上傳欄位。車牌、車種、違規日期、違規時間會自動填入，面板上會列出填了什麼。這一步不需要解鎖也能使用。
2. 在面板的「常用地點」「常用違規」選好項目，按「套用」。
3. 確認內容、勾選同意、送出。

換一支影片會以新影片的資料覆寫；移除影片會清空車牌、車種、日期與時間。

### 儲存常用地點與常用違規

先在網站的表單上手動選好地址或違規事項，再按面板上對應區塊的「目前內容存為常用」並取一個名稱。改名與刪除在設定頁進行。

### 匯出與匯入

設定頁可以把常用地點與常用違規匯出成 JSON 檔，重新安裝擴充功能後再匯入。匯出檔不含個人資料與主密碼，但**沒有加密**，用完請刪除或妥善保管。

## 安全設計

- 個人資料、常用地點、常用違規合成一份，以 AES-GCM 256 加密後才存入 `chrome.storage.local`。金鑰由主密碼經 PBKDF2-SHA256（600,000 次）推導。
- 解鎖後的金鑰只放在記憶體（`chrome.storage.session`），關閉瀏覽器即消失。
- 主密碼只在擴充功能自己的視窗輸入，不會出現在檢舉網站的頁面上。
- 解密只在背景的 service worker 進行；檢舉頁面上的程式只會拿到當下那一頁需要的欄位。
- 權限只有 `storage` 與 `alarms`，只在檢舉系統的網址上執行。
- 不使用任何外部函式庫，沒有任何連網的程式碼。

不想只看說明的話，[VERIFY.md](VERIFY.md) 列出了不必讀程式碼就能自己檢查的步驟，例如確認硬碟上搜不到自己的手機號碼。完整的設計說明在 [SPEC.md](SPEC.md)。

### 這個工具保護不到的地方

- 資料填進網站的表單之後，就和你自己手打的一樣，不在加密範圍內。Chrome 內建的自動填入如果開著，可能會另外把它記下來，建議關閉「儲存並填入地址」。
- 加密的強度取決於主密碼，請用夠長的密碼。

## 注意事項

- 檢舉系統改版時，工具可能會失效。找不到預期的欄位時，面板會顯示「頁面結構可能改版」並停止填寫，不會亂填。
- 送出前請自己再確認一次內容，尤其是車牌與時間。
